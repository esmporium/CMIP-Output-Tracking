Added the daily search-and-notification job.

`make run-search-and-notifications` searches ESGF for the datasets we are tracking,
records the results in a local database,
prints a summary of what has changed since the last run
and emails that summary to a list of recipients.
The first search tracked is the pattern effect use case:
monthly `tas` from the CMIP7 historical experiment.

See ["How to run the daily search"][how-to-run-the-daily-search]
for how to configure the mail settings and put the job on a cron schedule.
